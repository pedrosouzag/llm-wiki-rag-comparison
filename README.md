# LLM-Wiki vs RAG

Projeto de Iniciação Científica voltado à avaliação e comparação entre **LLM-Wiki** e **RAG (Retrieval-Augmented Generation)** para construção e consulta de bases de conhecimento verificáveis.

## Sobre o projeto

O projeto busca investigar em quais cenários uma base de conhecimento construída e mantida por LLMs, organizada em páginas Markdown, é suficiente para responder perguntas e em quais situações a recuperação dinâmica de informações externas por meio de RAG se torna necessária.

A abordagem **LLM-Wiki** utiliza uma base de conhecimento estruturada, composta por páginas Markdown, que pode ser construída, atualizada e organizada com auxílio de LLMs.

Já a abordagem **RAG** utiliza a recuperação dinâmica de documentos relevantes para fornecer informações adicionais ao modelo durante a geração das respostas.

## Objetivo

O objetivo principal é **avaliar e comparar as abordagens LLM-Wiki e RAG** em tarefas de resposta a perguntas baseadas em conhecimento verificável.

A comparação considerará aspectos como:

- Acurácia das respostas
- Atualidade das informações
- Consistência
- Fidelidade às informações disponíveis
- Capacidade de citar fontes
- Robustez diante de diferentes tipos de consultas
- Comportamento com o aumento da quantidade de informações
- Limitações e pontos de falha de cada abordagem

## Metodologia

O projeto envolve a construção de uma base de conhecimento no formato LLM-Wiki e a implementação de um pipeline baseado em RAG.

Serão utilizadas perguntas de diferentes níveis de especificidade, atualidade e complexidade para avaliar as duas abordagens.

Os resultados serão analisados de forma quantitativa e qualitativa, buscando compreender as características, limitações e possibilidades de cada estratégia.
